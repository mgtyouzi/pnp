# Prototype Experiment Results

This directory contains lightweight, inspectable outputs from the P2P prototype experiments.

Included files are evaluation summaries, audit reports, CSV/JSON/JSONL metrics, text reports, and selected plots.

Intentionally excluded:

- model checkpoints (`.pth`, `.pt`, `.ckpt`)
- feature/data caches (`.npz`)
- datasets and archives
- runtime logs and process files

The original experiment directory names are preserved so each report can be mapped back to its run.
